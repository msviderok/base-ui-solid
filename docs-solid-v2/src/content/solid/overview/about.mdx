# About Base UI

<Subtitle>A headless, unstyled React component library — now for Solid.</Subtitle>

Base UI is a library of headless ("unstyled") React components and low-level hooks. It includes prebuilt components with the baked-in behaviors and accessibility features you need, but none of the styles — giving you complete freedom over how they look.

This Solid port brings the same components and APIs to the [Solid.js](https://www.solidjs.com/) ecosystem.
