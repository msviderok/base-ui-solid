# Accessibility

<Subtitle>How Base UI approaches accessibility.</Subtitle>

Base UI components are designed with accessibility in mind and implement the [WAI-ARIA design patterns](https://www.w3.org/WAI/ARIA/apg/) where applicable.

## Keyboard navigation

All interactive components support keyboard navigation. Components use the appropriate ARIA roles, properties, and states to communicate their behavior to assistive technologies.

## Screen readers

Components are designed to work with screen readers. They use semantic HTML elements and appropriate ARIA attributes to provide a good experience for screen reader users.
