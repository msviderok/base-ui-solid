# Direction Provider

<Subtitle>Provides text direction context to Base UI components.</Subtitle>

The Direction Provider sets the text direction (`ltr` or `rtl`) for all nested Base UI components.

## Anatomy

```jsx title="Anatomy"
import { DirectionProvider } from '@msviderok/base-ui-solid/direction-provider';

<DirectionProvider direction="rtl">
  {/* components */}
</DirectionProvider>;
```
